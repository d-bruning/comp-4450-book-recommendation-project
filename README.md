# COMP 4450: Book Recommendation System

## Overview

Get Recc'd is an end-to-end cloud deployed book recommendation system built using collaborative filtering, FastAPI, Streamlit, Docker, DynamoDB, AWS EC2, MLflow, Weights & Biases (W&B), automated testing, and CI/CD.

The system allows a user to select a favorite book and receive recommendations generated by a K-Nearest Neighbors (KNN) recommendation model. The application includes operational monitoring, cloud-native persistence, experiment tracking, model registry capabilities, containerized deployment, and AWS infrastructure.

Configuration is controlled through:

```text

├── development.yml
├── production.yml
└── loader.py
```

#### Development Environment

```yaml
storage:
  provider: local
```

Uses:

```text
logs/prediction_logs.jsonl
logs/recommendation_cache.json
```

#### Production Environment

```yaml
storage:
  provider: dynamodb
```

Uses:

```text
prediction-history
recommendation-cache
```

Application and monitoring services dynamically select storage providers through configuration without requiring code changes.

## Key Technical Challenges

### Metadata Deployment

A filename mismatch between `book_metadata.csv` and `books_metadata.csv` caused missing author and image metadata.

### AWS Authentication

Initial DynamoDB integration failed with `NoCredentialsError` and was resolved through IAM role assignment.

### Container Deployment

Docker Compose and Buildx installation on EC2 required additional configuration.
